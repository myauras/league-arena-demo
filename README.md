# League Arena — 英雄競技場

手機與桌面共用的直式網頁展示。選擇英雄及玩法，觀看五位英雄的共同戰鬥影片，依最終名次結算測試點數。

提供冠軍、前二、前三、前二順位、前兩組五種玩法。影片與結果不因玩家選擇而改變；下注標記、血條、個人擊殺後製及死亡灰階由瀏覽器疊加。

目前發布內容只保留十支新版影片，五位英雄各有兩場獲勝影片。影片版本為 `c7ef4e4e24ac465e4d26`，畫面規格為 720×900、60 fps。

公開遊玩：https://myauras.github.io/league-arena-demo/

目前使用網頁壓縮版，每場約 4.9–7.2 MB，十場共 58.3 MB，保留原解析度、60 fps、完整影格時序和原音軌。影片檔名包含內容雜湊。

點數與續播紀錄保存在各自瀏覽器，初始為 10,000 測試點數，不跨裝置同步。這是展示用途，不涉及實際金額，也不是正式帳號或結算服務。

## GitHub Pages

將 Pages 的來源設定為 `Deploy from a branch`，選擇 `main` 與 `/ (root)`。入口為此目錄的 `index.html`；`.nojekyll` 保留原始靜態檔案。

資源會自動以目前目錄為基準，支援 GitHub 專案子網址。MP4 在匯出時驗證 SHA-256 與影格／音軌；timeline 在播放前驗證 SHA-256。GitHub 支援 HTTP Range，因此影片邊載入邊播放，快轉由瀏覽器請求需要的區段。沒有 Range 的主機則使用完整下載及 SHA-256 驗證後的 Blob 播放。

舊版影片已移除。尚未看完的舊回合直接顯示原本已結算的名次與返還，保留下注、結果與餘額，不改抽別支影片、不重複扣點；按下一局即可播放新版。現行版本的未完回合仍可正常續播。

請以 HTTP 或 HTTPS 開啟，不要直接雙擊 HTML。
